# 8080A-Programs-and-Subroutines
1970s 1980s era Intel 8080A /  8085A / 80C85 Assembly Language Level software examples for sharing

Purpose:
     * to share 1970 and 1980s era 8080A Assembly language programs and subroutines
     * Target products:
          >> IMSAI non Front Panel PCS series like the PCS 80/30 
          >> IMSAI 8080A system with a Front Control Panel 
          >> MITS/Altair 8800 system with MITS/Altair Front Panel

Errata:  None Known, these programs worked on my PCS80/30 of 1977 vintage

contact email:  greglori_mi@wowway.com


Answers to Questions people asked:

Q:  some people claimed GitHub lacked 8080A 1970s era software examples
A:  OK, I uploaded some files into GitHub for sharing.  More will be added as time goes by.
 
Q:  Where is C or C++ or Viper?
A:  Those didn't exist in 1975, back then there was mostly CPU level Assembly Language code, Fortran, BASIC and COBOL.
    The IO driver subroutines of 1975 are similar to those in modern BIOS DLL drivers (device level).
    Early CP/M was starting to come out of development.

WARNING: GITHUB files are from OCR converted ink jet line printer paper output.
          OCR conversion was not 100%, some conversion errors might still exist after correction effort.
          Most common mis reads are OCR sees a B instead of E, I instead of T, and any tilde character "~".
